# 🚀 LifeOS – All-in-One Personal Life Manager

**LifeOS** is a smart personal productivity platform designed to manage everyday activities in one place. It helps users organize tasks, track expenses, monitor study progress, maintain daily habits, and analyze their productivity through interactive dashboards.

## ✨ Key Features

- **Dashboard:** View your daily activities and productivity overview.
- **Task Manager:** Add, complete, and delete tasks with priorities and due dates.
- **Expense Manager:** Record and organize daily expenses by category.
- **Study Tracker:** Manage subjects, track topic completion, and record study sessions.
- **Habit Tracker:** Create daily habits and monitor completion.
- **Analytics Dashboard:** Visualize tasks, expenses, study hours, and habit consistency.
- **Life Score:** Get a daily productivity score based on tasks, study, and habits.
- **Productivity Insights:** Receive feedback based on your daily Life Score.
- **Responsive Design:** Access the platform on laptop and mobile screens.

## 📊 Life Score Calculation

LifeOS calculates a custom daily productivity score out of 100:

- Task Completion – 40%
- Study Progress – 30%
- Habit Completion – 30%

The score provides a simple personal productivity indicator, not a scientific assessment.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Pranavmankar260306/My_LifeOS.git
```

### 2. Open the project folder

```bash
cd My_LifeOS
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in your browser

```text
http://127.0.0.1:5000/
```
